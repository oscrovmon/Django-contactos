## Django

Django es un framework de desarrollo web creado en Python que proporciona las herramientas necesarias para construir sitios web dinámicos, seguros y escalables sin escribir todo el código base desde cero.

Su estructura interna divide la aplicación en cuatro capas de responsabilidad:

    Enrutador de URLs: Identifica la ruta de la petición web realizada por el usuario y la canaliza hacia la lógica correspondiente.

    Vista: Ejecuta la lógica de negocio. Recibe la petición, procesa la información necesaria interaccionando con los datos y selecciona la respuesta adecuada.

    Modelo: Define la estructura de los datos mediante clases de Python. Gestiona el acceso, la lectura y la escritura en la base de datos de manera automática.

    Template: Genera la interfaz de usuario. Son plantillas que combinan código HTML con variables dinámicas que se completan antes de enviar el resultado final al navegador.

Su funcionalidad distintiva es que incluye de forma nativa módulos para la autenticación de usuarios, la prevención de vulnerabilidades de seguridad comunes y un panel de administración para la gestión de datos.
